# VICTOTALCOACH

Planificación de entrenamientos, ejercicios, pizarras tácticas y scouting para balonmano, fútbol, baloncesto y voleibol.

- Abre la aplicación: `VICTOTALCOACH.html` (o la raíz de la web).
- Comprobar instalación e iconos: `diagnostico.html`.
- **Los datos no están en este repositorio**: cada navegador guarda los suyos. Las copias de seguridad (`.json`) se descargan desde la propia aplicación y **no deben subirse nunca aquí**.
